# Design skills grid

Generated by `research/build-skills-grid.py` from every `SKILL.md` in the cloned skill repos under `repos/` plus the design skills already installed on this Mac (`~/.claude/skills`, impeccable, taste-skill, frontend-design, figma and design plugins).

`name` = installed and invocable now. `name*` = only in a clone, not installed. Non-design skills (business, code architecture, docx/pdf, Vercel deploy, repo-internal dev workflows in opencode/gemini-cli/motion/json-render) are excluded.

## Start here (orchestrators, not specialists)

| Skill | What it does | When |
|---|---|---|
| `design-director` | Thinks with you. Explore a new product's direction, audit an existing one, or plan a redesign. Writes `.design/brief.md` or `.design/audit.md`. Never edits product code. | You do not know what it should look like, what is wrong, or which specialist to use. |
| `design-builder` | Executes an approved brief against the codebase: tokens, layout, components, copy, motion, responsive, a11y, then review-and-fix loops. | A brief is approved, or an audit's fix list is accepted. |

Both live in `skills/` and resolve specialists through `skills/design-director/reference/catalog.json` + `playbook.md`. Experts skip them and call any specialist below directly.
